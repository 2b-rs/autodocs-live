# autodocs-live

Live-Schicht der autodocs-Website (CONCEPT-0061): append-only, hash-verkettetes Entscheidungsprotokoll der
Kontextverteilung (Snippets und Schaubild-Beschreibungen an Spezifikationselemente und Fragmente).

* Geschrieben ausschließlich vom Workflow `live-distribution.yml` in `2b-rs/autodocs` (Deploy-Key).
* Datenpakete (`data-<datum>`) hängen als Release-Assets an diesem Repo; sie enthalten keine PDFs und keine Geheimnisse.
* Zusammengeführt wird lokal beim nächsten Neubau (`_src/tools/live_consolidate.py`).
